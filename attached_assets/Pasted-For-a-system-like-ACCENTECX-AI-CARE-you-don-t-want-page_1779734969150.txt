For a system like ACCENTECX AI CARE, you don’t want “pages everywhere.” You want **clear role-based surfaces**. Think in terms of **who uses what screen to do what job**.

A clean, production-ready SaaS like this needs:

---

# 1. CORE PUBLIC WEBSITE (LANDING SYSTEM)

## You need: **1 main landing system (5–7 sections, not separate pages)**

### Pages (public-facing)

1. **Landing Page (Home)**

   * problem → solution → how it works → pricing → CTA

2. **How It Works Page**

   * parent flow explanation
   * doctor flow explanation
   * video + AI workflow

3. **Pricing Page**

   * 3 tiers
   * clinic/school pricing
   * FAQ

4. **About / Mission Page**

   * credibility, healthcare mission, partners

5. **FAQ Page**

   * diagnosis disclaimer
   * data privacy
   * AI explanation

6. **Login / Register Page**

7. **Legal Pages**

   * Privacy Policy
   * Terms
   * Medical disclaimer

👉 So: **5–7 public pages total**

# 5. IMPORTANT DESIGN RULE (MOST PEOPLE GET THIS WRONG)

Do NOT create dashboards per feature.

Instead:

## ❌ WRONG:

* screening dashboard
* video dashboard
* therapy dashboard
* booking dashboard

## ✅ CORRECT:

* ONE Parent Dashboard containing everything
* ONE Doctor Dashboard containing everything
* ONE Admin Dashboard containing everything

Each dashboard is just:

> a role-based workspace
