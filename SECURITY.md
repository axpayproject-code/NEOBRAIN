# Security policy

Do not post credentials, personal data, client datasets, or exploitable vulnerability details in public issues.

When this project is hosted on GitHub, use **Report a vulnerability** in the repository's Security tab for private reports. The repository owner should enable private vulnerability reporting before inviting public use. Until then, contact a maintainer through a private channel listed on the repository page.

This is a local pilot, not a hardened multi-tenant service. Do not expose it publicly with client data until authentication, authorization, storage, and deployment security have been reviewed.
