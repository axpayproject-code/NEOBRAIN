# Roadmap

This is a community proposal list, not a promise of delivery. Open an issue before starting a substantial item.

## Available for contribution

- Improve CSV header/unit detection using documented, synthetic examples.
- Add tests for missing dates, missing values, leap days, and edge cases in rainfall windows.
- Improve accessibility, localization, and small-screen layouts.
- Add source freshness and provenance validation.

## Needs local partners and validation

- Compare the NASA POWER point series with authorized PAGASA station or CliMap observations.
- Define municipal climate coverage and acquire boundary geometry with clear redistribution terms.
- Add crop, irrigation, and water-supply context with local agency or client validation.
- Review candidate indicators with PAGASA, agriculture, water, and local-response partners.

## Later, after a pilot owner is identified

- Add persistent multi-user preparedness tracking, access control, backups, and audit history.
- Set up scheduled data refresh, monitoring, and a reviewed hosting environment.
- Build municipality comparisons only when supported by suitable local data.
